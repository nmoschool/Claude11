# منصة «لغتي» — الصف الرابع الابتدائي (بنات)

منصة ويب عربية (RTL) لمعلمة لغتي: سجل الدرجات، توزيع المنهج، ملفات الطالبات،
مولد الاختبارات، والألعاب التعليمية — مع واجهة قراءة فقط للمشرفة التربوية.

- **وثيقة التصميم الكاملة:** [`docs/lughati-g4-design.md`](docs/lughati-g4-design.md)
- **الستاك:** Next.js 15 · TypeScript · Prisma · PostgreSQL · NextAuth · Tailwind · Zod

## حالة التنفيذ

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1. التأسيس | المخطط الكامل للقاعدة، الصلاحيات الدقيقة، 2FA، دخول الطالبات بالصور، إدارة المستخدمين، سجل التدقيق | ✅ مكتملة |
| 2. المنهج والطالبات | التوزيع والتقويم، الملف الفردي (حضور/سلوك/ملاحظات/ملفات)، الاستيراد من «نور» | ✅ مكتملة |
| 3. سجل الدرجات | الأوزان، الحساب التلقائي، الاعتماد، التحليل المهاري، التقارير PDF/CSV/Excel/«نور» | ✅ مكتملة |
| 4. الأسئلة والاختبارات | بنك الأسئلة (11 نوعاً)، التطبيع العربي، المولّد والنماذج، PDF، الحل الإلكتروني | ✅ مكتملة |
| 5. الألعاب | 6 ألعاب، نقاط ومستويات وأوسمة، شهادات بتحقق QR، لوحة المعلمة، اللعب دون اتصال | ✅ مكتملة |
| 6. الإطلاق | الاستضافة، النسخ الاحتياطي، اختبارات الحمل | ⏳ |

## ما تقدمه المرحلة 1

**الأدوار:** مدير النظام · قائدة المدرسة · معلمة · مشرفة (قراءة فقط) · طالبة.

**الصلاحيات:** 24 صلاحية بصيغة `مورد:إجراء` (`src/lib/permissions.ts`). لكل دور
افتراضيات، ويمكن منح أو سحب أي صلاحية لمستخدمة بعينها من «المستخدمون والصلاحيات».
تُفحص في كل طلب API من القاعدة مباشرة، فالسحب أو التعطيل يسري فوراً.

**ضمانات المشرفة:** لا يمكن منحها أي صلاحية كتابة حتى بالتخصيص، ويرفض الخادم أي
طلب كتابة منها خارج «الملاحظات الإشرافية» وإعدادات حسابها. البيانات الحساسة
(جوال ولي الأمر، الملاحظات الصحية) تظهر لها مخفية.

**نطاق الفصول:** المعلمة والمشرفة تريان فصولهما المسندة فقط؛ القائدة ترى المدرسة كاملة.

**منع التصعيد:** لا تعدّل المستخدمة دورها أو صلاحياتها بنفسها، ولا يُعدَّل حساب
مدير النظام إلا منه، ولا تُمنح صلاحية خارج ما يُسمح للمديرة بمنحه.

**دخول الطاقم:** بريد + كلمة مرور (bcrypt) + **تحقق ثنائي TOTP إلزامي** يُطلب
إعداده عند أول دخول. قفل 15 دقيقة بعد 5 محاولات خاطئة. الجلسة 8 ساعات.

**دخول الطالبات:** رمز الفصل (6 أحرف) ← اختيار الاسم والصورة الرمزية ← 4 صور سرية
بالترتيب، مع قراءة صوتية للتعليمات. قفل 10 دقائق بعد 5 محاولات خاطئة، والجلسة 60 دقيقة.
المعلمة تولّد الرموز وتطبع بطاقات الدخول من صفحة الفصل. الرموز تظهر مرة واحدة فقط،
والمخزَّن تجزئة bcrypt.

**حماية البيانات:** رقم الهوية وجوال ولي الأمر والملاحظات الصحية مشفّرة بـ
AES-256-GCM على مستوى التطبيق. كل اطلاع على البيانات الحساسة يُسجَّل.

**سجل التدقيق:** الدخول، المحاولات الفاشلة، تفعيل 2FA، إنشاء المستخدمين وتعديلهم،
تغيير الصلاحيات، توليد رموز الطالبات، الاطلاع على البيانات الحساسة، والملاحظات الإشرافية.

## ما تقدمه المرحلة 2

**توزيع المنهج** (`/dashboard/curriculum`)
- عرض أسبوعي للفصل الدراسي بالتاريخين الهجري والميلادي، مع مؤشر التغطية (المنفّذ مقابل المخطط حتى الأسبوع الحالي) وعدد الدروس المتأخرة.
- تحرير الدرس: العنوان، المكوّن، الحصص، الأهداف، المهارات، الحالة (مخطط / منفّذ / مؤجّل).
- **إعادة الجدولة**: نقل درس وحده أو مع إزاحة كل ما بعده. أسابيع الإجازة تُتخطّى تلقائياً، والمعاينة تُظهر ما سيتحرك وما سيتجاوز نهاية الفصل قبل الحفظ. زر «تأجيل أسبوع» يفعل ذلك بضغطة.
- **الاستيراد من Excel/CSV** بالاستبدال أو الإضافة، مع معاينة تبيّن أخطاء كل صف. القالب الجاهز يُستورد كما هو.
- إدارة الإجازات، وطباعة التوزيع.

**التقويم** (`/dashboard/classes/:id/calendar`)
- شهري بالتاريخين، ويعرض أسابيع الخطة والإجازات وأحداث الفصل (واجب، اختبار قصير/فتري/نهائي، نشاط).
- **السحب والإفلات لإعادة الجدولة**، مع حفظ التاريخ الأصلي. الجمعة والسبت مرفوضان.
- تصدير iCal لتقويم الجوال أو Outlook.

**الطالبات**
- إضافة وتعديل وأرشفة واستعادة. لا حذف نهائي للبيانات.
- **الاستيراد من «نور»**: مطابقة أعمدة تلقائية قابلة للتعديل، وتطبيع الأرقام العربية وصيغ الجوال (+966…). تُطابق الطالبات ببصمة رقم الهوية فلا تتكرر: الموجودة تُستكمل بياناتها الناقصة، والمسجلة في فصل آخر تظهر كتعارض. المعاينة لا تكشف الهوية كاملة.
- **الملف الفردي**:
  - البيانات (الحساسة منها مشفّرة)
  - الحضور مع خريطة ونسبة وتنبيه الغياب المتتالي
  - السلوك (إيجابي / يحتاج متابعة بالنقاط)
  - الملاحظات (أكاديمية / تواصل / خطة علاجية / إشرافية، ويمكن إخفاؤها عن المشرفة)
  - الملفات
- **الحضور اليومي** للفصل بضغطة لكل طالبة، مع تنبيه عند 3 أيام غياب متتالية بدون عذر.

**أمان الملفات**
- يُفحص نوع الملف الحقيقي من محتواه لا من امتداده (PDF، JPG، PNG، MP3، M4A)، والحد 10 ميجابايت.
- تُزال البيانات الوصفية من الصور (الموقع الجغرافي ونوع الجهاز).
- التخزين في مجلد خاص أو حاوية S3 خاصة، والتنزيل عبر الخادم بعد التحقق من الصلاحية.
- التقارير الطبية لا تظهر إلا لمن يملك صلاحية البيانات الحساسة.
- لا تُكتب قيم الهوية أو الجوال في سجل التدقيق.

## ما تقدمه المرحلة 3

**سجل الدرجات** (`/dashboard/gradebook`)
- جدول شبكي: الطالبات صفوف والتقييمات أعمدة مجمّعة تحت مكوّناتها. الحفظ تلقائي لكل خلية، ويُتراجع عنه إن فشل.
- التنقل بلوحة المفاتيح (Enter / Shift+Enter / الأسهم). «غ» غائبة و«ع» بعذر، والأرقام العربية مقبولة.
- **لصق عمود أو جدول من Excel** دفعة واحدة، مع رفض اللصق كله إن كانت فيه قيمة غير صالحة.
- تلوين شرطي: أحمر دون 50٪، أصفر 50–69٪، أخضر من 90٪.
- صف إحصاءات لكل تقييم: المتوسط، والوسيط، والانحراف المعياري، والأدنى والأعلى، ونسبة الإتقان.
- «إدخال سريع» بطاقة لكل طالبة لاستخدامه من الجوال أثناء الحصة.
- يعاد الحساب فوراً في المتصفح بنفس دوال الخادم.

**الحساب** (`src/lib/gradeCalc.ts`، و20 حالة محسوبة يدوياً في `tests/gradeCalc.test.ts`)
- درجة المكوّن = مجموع المحصّل ÷ مجموع العظمى × الوزن (تجميع وليس متوسط نسب).
- «بعذر» يُستبعد من الحساب، و«غائبة بلا عذر» صفر (قابل للتعطيل).
- المجموع يُعاد تطبيعه على المكوّنات المرصودة، مع مؤشر «اكتمال الرصد».
- سلم التقديرات قابل للتخصيص.

**الأوزان** (`/dashboard/gradebook/settings`)
- مكوّنات وأوزان وسلم تقديرات لكل فصل دراسي. يُشترط أن يكون المجموع 100.
- لا يُحذف مكوّن عليه درجات، وتُجمَّد الأوزان بعد اعتماد أي فصل.

**الاعتماد (القفل)**
- صلاحية `grades:lock`. بعد الاعتماد تُمنع إضافة التقييمات وتعديلها.
- أي تصحيح لدرجة يتطلب **سبباً**، ويُسجَّل في التدقيق بالقيمة القديمة والجديدة.
- فك الاعتماد يتطلب سبباً كذلك.

**التقارير** (`/dashboard/reports`)
- **بطاقة الطالبة**: المجموع والتقدير ومتوسط الفصل والترتيب، والمكوّنات، والإتقان المهاري مقارنة بالفصل، ونقاط القوة، والمهارات التي تحتاج دعماً، والحضور، وملاحظات المعلمة، وخانات التوقيع.
- **التقرير الجماعي**: المؤشرات، وتوزيع التقديرات، ومتوسطات المكوّنات، وخريطة حرارية للمهارات، وقائمة الدعم العلاجي.
- **كشف الدرجات**: A4 أفقي بكل التقييمات والمكوّنات.
- **PDF** من الخادم عبر Chromium (اتصال الحروف العربية سليم)، والطباعة من المتصفح بديل بنفس القالب.
- **CSV** (UTF-8 مع BOM، ومحمي من حقن الصيغ) و**Excel**، و**ملف «نور»** يحوي درجات المكوّنات فقط. رقم الهوية فيه لا يظهر إلا لمن يملك صلاحية البيانات الحساسة.

## ما تقدمه المرحلة 4

**بنك الأسئلة** (`/dashboard/assessments/bank`)
- 11 نوعاً: اختيار من متعدد، صواب وخطأ، ملء فراغ، توصيل، تصنيف، ترتيب كلمات، استخراج من نص، تحويل، إملاء صوتي، سؤال مفتوح، ونص فهم مقروء بأسئلة فرعية.
- كل سؤال موسوم بالمهارة والدرس والصعوبة والدرجة. محرر خاص بكل نوع، مع تحقق متبادل بين البيانات والمفتاح.
- السؤال المستخدم في اختبار لا يتغير مفتاحه ولا درجته، والحذف يصبح أرشفة، حتى لا تتغير نتائج سابقة.
- **مولّد قواعدي من قاموس المفردات**:
  - اللام الشمسية/القمرية والتاء المربوطة/المفتوحة تُحدَّد من الكلمة نفسها.
  - المثنى (بصيغتيه) والجمع والأضداد والمعاني تُؤخذ من المفردات المسجلة.
  - الناتج مسودات تراجعها المعلمة قبل الحفظ.

**التصحيح الآلي العادل** (`src/lib/arabicNormalize.ts` و`src/lib/autoGrade.ts`)
- **وضع إملائي صارم** لأسئلة الرسم الإملائي (الهمزة والتاء والألف المقصورة مقاسة).
- **وضع متساهل** لأسئلة النحو والفهم (لا عقاب على خطأ إملائي).
- في الوضعين يُزال التشكيل والتطويل والترقيم.
- درجة جزئية للتوصيل والتصنيف والاستخراج، ويُقبل أكثر من ترتيب صحيح للجملة.

**المولّد والنماذج** (`/dashboard/assessments/new`)
- جدول مواصفات (مهارة × نوع × صعوبة × عدد) ونطاق دروس، مع قوالب جاهزة.
- اختيار متوازن ينوّع الدروس ويُبلغ عن نقص البنك.
- معاينة قبل الحفظ، مع إمكانية الحذف وإعادة الترتيب.
- **حتى 3 نماذج (أ/ب/ج)** تُخلط فيها الأسئلة والخيارات من بذرة ثابتة، فيُعاد بناء أي نموذج ومفتاحه في أي وقت. النص القرائي يبقى متصلاً بأسئلته.

**الطباعة**
- ورقة الطالبة A4 لكل نموذج، ونموذج الإجابة للمعلمة. السؤال لا ينقسم بين صفحتين.
- **دفعة أوراق للفصل** باسم كل طالبة ونموذجها.
- PDF من الخادم بنفس القالب.

**الحل الإلكتروني للطالبات** (`/student/assessments`)
- أزرار كبيرة، وقراءة صوتية لكل سؤال، وإملاء صوتي.
- ترتيب الكلمات واستخراجها بالضغط عليها.
- حفظ تلقائي واستئناف، ومؤقت بتسليم آلي عند انتهاء الوقت.
- **مفتاح الإجابة لا يُرسل إلى جهاز الطالبة إطلاقاً**، والتصحيح على الخادم.
- توزيع النماذج على الطالبات بالتناوب.

**النتائج** (`/dashboard/assessments/results/:id`)
- حالة كل طالبة، وتصحيح يدوي للأسئلة المفتوحة.
- **نقل الدرجة تلقائياً إلى سجل الدرجات** عند اكتمال التصحيح. إن كان السجل معتمداً لا تُكتب الدرجة وتنبَّه المعلمة.
- **تحليل الأسئلة**: معامل السهولة، ومعامل التمييز (أعلى 27٪ مقابل أدنى 27٪)، وأكثر الإجابات الخاطئة شيوعاً، وملاحظات للأسئلة السهلة جداً أو الصعبة جداً أو ضعيفة التمييز. لا تظهر الملاحظات قبل 5 محاولات.

## ما تقدمه المرحلة 5

**الألعاب** (`/student/games`): ست ألعاب مرتبطة بمهارات المنهج، جلسة كل منها 10 جولات.

| اللعبة | المهارة | المستويات |
|---|---|---|
| 🌻 حديقة الشمس والقمر | اللام الشمسية والقمرية (تُحدَّد من الكلمة نفسها) | بلا مؤقت ← 10 ثوانٍ ← 6 ثوانٍ |
| 🚂 قطار الجملة | ترتيب الجملة، وتقبل كل ترتيب صحيح | 3 كلمات ← 4 ← أطول |
| 🎣 صائدة التاء | التاء المربوطة والمفتوحة | خياران ← ثلاثة (ـه مشتّت) ← مع مؤقت |
| 🏭 مصنع المفرد والمثنى والجمع | الصنف اللغوي، مع مشتّتات من الأخطاء الشائعة («مدرسةان») | مثنى ← جمع ← مختلط |
| 🃏 بطاقات الأضداد | المفردات | 3 أزواج ← 4 ← 6 |
| 🔊 إملاء الصدى | الإملاء الصوتي (مطابقة إملائية صارمة) | كلمات سهلة ← تاء ← همزات وألف لينة |

- **صعوبة تكيفية**: 3 إجابات صحيحة متتالية ترفع المستوى، وخطآن متتاليان يخفضانه.
- تلميح لكل جولة، وتغذية راجعة صوتية لطيفة بلا أصوات عقابية، وقراءة صوتية لكل كلمة.
- المحتوى: كلمات مدمجة (تخضع لاختبارات قواعدية آلية) مع **مفردات منهج المدرسة** و**أسئلة «ترتيب الكلمات» من بنك الأسئلة**.

**التحفيز** (`src/lib/gamification.ts`)
- **النقاط تُحسب على الخادم** ولا تُقبل من الجهاز: صحيحة 10، بلا تلميح +5، كل 5 متتالية +20. لا خصم أبداً.
- سقف يومي 1500 نقطة.
- الإجابات الأسرع من 200 ملّي ثانية **لا تمنح نقاطاً ولا أوسمة**، وتُسجَّل للتحليل فقط.
- **خمسة مستويات**: 🌱 برعم ← 🌸 زهرة ← ⭐ نجمة ← 🌙 قمر ← ☀️ شمس اللغة.
- **سبعة أوسمة**، منها «المتحسّنة» (تحسّن 20٪ في مهارة)، وفيها تركيز على التحسن لا التفوق فقط.
- **لوحة الشرف** على مستوى الفصل بالاسم الأول فقط: أعلى 5، والأكثر تقدماً هذا الأسبوع. تستطيع المعلمة إخفاءها.

**الشهادات**
- تصدر تلقائياً عند بلوغ مستوى أو نيل وسام، ويدوياً من المعلمة.
- قالب A4 أفقي فيه **رمز QR** يفتح صفحة تحقق عامة `/verify/:code`. صفحة التحقق تعرض الاسم الأول وأول حرف من اسم العائلة فقط.
- تُطبع أو تُحفظ PDF من حساب الطالبة، أو من الخادم للمعلمة.

**اللعب دون اتصال**
- عامل خدمة يخزّن صفحات الألعاب وحزمة المحتوى فقط. لا يُخزَّن أي بيانات شخصية أو واجهات كتابة.
- المحاولات تُحفظ في الجهاز **لكل طالبة على حدة** (الأجهزة اللوحية مشتركة).
- المزامنة تلقائية عند عودة الاتصال، و**بلا تكرار**: كل محاولة لها معرّف فريد يتجاهل الخادم إعادته.

**لوحة المعلمة** (`/dashboard/games`)
- لكل لعبة: المحاولات، واللاعبات، والدقة، والوقت.
- الدقة حسب المهارة (الأضعف أولاً)، و**أصعب العناصر على الفصل**، ومن لم تلعب هذا الأسبوع.
- تفعيل وتعطيل الألعاب لكل فصل، وإصدار شهادات تقدير يدوية.

## التشغيل

```bash
docker run -d --name lughati-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=lughati -p 5432:5432 postgres:16-alpine
npm install
cp .env.example .env          # اضبطي NEXTAUTH_SECRET و FIELD_ENCRYPTION_KEY
npm run db:push
npm run db:seed               # ⚠️ يمسح القاعدة ويعبئ بيانات تجريبية ويطبع رموز دخول نموذجية
npm run dev
```

## ملاحظات معروفة

- **حد المحاولات بالذاكرة:** `src/lib/rateLimit.ts` يناسب خادماً واحداً، ويُستبدل بـ Redis عند تشغيل عدة نسخ.
- **الاعتماديات:** استُبدلت `xlsx` بـ `exceljs`، وحُدّثت Next.js إلى 15.5.29 (إصلاح ثغرة حرجة). `npm audit --omit=dev` يعطي 0 ثغرات.
- **تواريخ الميلاد الهجرية** في ملفات «نور» لا تُستورد حالياً وتُدخل يدوياً.
- **مخطط الأوزان مشترك** لكل فصول الصف الرابع في الفصل الدراسي (سياسة المدرسة)؛ تعديله من معلمة يسري على الجميع ويُسجَّل.
- **الألعاب لا تُحتسب في سجل الدرجات** (تدريب فقط): إجاباتها تصل للجهاز ليعمل اللعب دون اتصال، فلا تصلح للتقييم الرسمي.
- **العمل دون اتصال يتطلب HTTPS** في بيئة الإنتاج (شرط من المتصفحات لعامل الخدمة)، ويتطلب فتح الألعاب مرة واحدة وأنتِ متصلة.
- **لعبتان من الثماني في التصميم مؤجلتان**: «محققة الأفعال» و«المسابقة المباشرة» على السبورة (تحتاج اتصالاً لحظياً).
- **الإملاء الصوتي**: الكلمة تُرسل إلى المتصفح لينطقها، فيمكن لطالبة متمرسة رؤيتها بأدوات المطوّر. الحل لاحقاً: رفع تسجيل صوتي من المعلمة بدلاً من النطق الآلي.
- **مولّد الأسئلة بالذكاء الاصطناعي** (اختياري في التصميم) غير مُفعّل؛ المولّد الحالي قواعدي حتمي.
- **تصحيح الأوراق بالكاميرا (OMR)** ضمن المرحلة الثانية بعد الإطلاق.
- **معايير التقدير (Rubrics) للمهام الأدائية** مؤجلة؛ تُرصد المهمة حالياً كدرجة واحدة.
- **إضافة إجازة لا تنقل الدروس تلقائياً**، فتستخدم المعلمة «تأجيل أسبوع» على أول درس متأثر.
- **تواريخ الفصلين الدراسيين في البذرة تقريبية**، وتُعدَّل وفق التقويم الرسمي.
