# منصة «لغتي» — الصف الرابع الابتدائي (بنات)

منصة ويب عربية (RTL) لمعلمة لغتي: سجل الدرجات، توزيع المنهج، ملفات الطالبات،
مولد الاختبارات، والألعاب التعليمية — مع واجهة قراءة فقط للمشرفة التربوية.

- **وثيقة التصميم الكاملة:** [`docs/lughati-g4-design.md`](docs/lughati-g4-design.md)
- **الستاك:** Next.js 15 · TypeScript · Prisma · PostgreSQL · NextAuth · Tailwind · Zod

## حالة التنفيذ

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1. التأسيس | المخطط الكامل للقاعدة، الصلاحيات الدقيقة، 2FA، دخول الطالبات بالصور، إدارة المستخدمين، سجل التدقيق | ✅ مكتملة |
| 2. المنهج والطالبات | التوزيع والتقويم، الملف الفردي (حضور/سلوك/ملاحظات/ملفات) | ⏳ |
| 3. سجل الدرجات | الأوزان، الحساب التلقائي، التقارير PDF/CSV | ⏳ |
| 4. الأسئلة والاختبارات | بنك الأسئلة، التصحيح الآلي العربي، PDF | ⏳ |
| 5. الألعاب | الألعاب، النقاط، الأوسمة، الشهادات | ⏳ |
| 6. الإطلاق | الاستضافة، النسخ الاحتياطي، اختبارات الحمل | ⏳ |

## ما تقدمه المرحلة 1

**الأدوار:** مدير النظام · قائدة المدرسة · معلمة · مشرفة (قراءة فقط) · طالبة.

**الصلاحيات:** 24 صلاحية بصيغة `مورد:إجراء` (`src/lib/permissions.ts`). لكل دور
افتراضيات، ويمكن منح أو سحب أي صلاحية لمستخدمة بعينها من «المستخدمون والصلاحيات».
تُفحص في كل طلب API من القاعدة مباشرة، فالسحب أو التعطيل يسري فوراً.

**ضمانات المشرفة:** لا يمكن منحها أي صلاحية كتابة حتى بالتخصيص، ويرفض الخادم أي
طلب كتابة منها خارج «الملاحظات الإشرافية» وإعدادات حسابها. البيانات الحساسة
(جوال ولي الأمر، الملاحظات الصحية) تظهر لها مخفية.

**نطاق الفصول:** المعلمة والمشرفة تريان فصولهما المسندة فقط؛ القائدة ترى المدرسة كاملة.

**منع التصعيد:** لا تعدّل المستخدمة دورها أو صلاحياتها بنفسها، ولا يُعدَّل حساب
مدير النظام إلا منه، ولا تُمنح صلاحية خارج ما يُسمح للمديرة بمنحه.

**دخول الطاقم:** بريد + كلمة مرور (bcrypt) + **تحقق ثنائي TOTP إلزامي** يُطلب
إعداده عند أول دخول. قفل 15 دقيقة بعد 5 محاولات خاطئة. الجلسة 8 ساعات.

**دخول الطالبات:** رمز الفصل (6 أحرف) ← اختيار الاسم والصورة الرمزية ← 4 صور سرية
بالترتيب، مع قراءة صوتية للتعليمات. قفل 10 دقائق بعد 5 محاولات خاطئة، والجلسة 60 دقيقة.
المعلمة تولّد الرموز وتطبع بطاقات الدخول من صفحة الفصل. الرموز تظهر مرة واحدة فقط،
والمخزَّن تجزئة bcrypt.

**حماية البيانات:** رقم الهوية وجوال ولي الأمر والملاحظات الصحية مشفّرة بـ
AES-256-GCM على مستوى التطبيق. كل اطلاع على البيانات الحساسة يُسجَّل.

**سجل التدقيق:** الدخول، المحاولات الفاشلة، تفعيل 2FA، إنشاء المستخدمين وتعديلهم،
تغيير الصلاحيات، توليد رموز الطالبات، الاطلاع على البيانات الحساسة، والملاحظات الإشرافية.

## التشغيل

```bash
docker run -d --name lughati-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=lughati -p 5432:5432 postgres:16-alpine
npm install
cp .env.example .env          # اضبطي NEXTAUTH_SECRET و FIELD_ENCRYPTION_KEY
npm run db:push
npm run db:seed               # ⚠️ يمسح القاعدة ويعبئ بيانات تجريبية ويطبع رموز دخول نموذجية
npm run dev
```

| الحساب | البريد | كلمة المرور |
|---|---|---|
| مدير النظام | `admin@school.sa` | `ChangeMe123!` |
| القائدة | `principal@school.sa` | `Principal123!` |
| معلمة (4/أ، 4/ب) | `teacher@school.sa` | `Teacher123!` |
| معلمة (4/ج) | `teacher2@school.sa` | `Teacher123!` |
| مشرفة (4/أ، 4/ب) | `supervisor@school.sa` | `Supervisor123!` |

> سيُطلب تفعيل التحقق الثنائي بتطبيق Google/Microsoft Authenticator عند أول دخول.
> غيّري كلمات المرور فوراً في أي بيئة حقيقية.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | PostgreSQL |
| `NEXTAUTH_SECRET` | سر توقيع الجلسات |
| `FIELD_ENCRYPTION_KEY` | 32 بايت base64 لتشفير الحقول الحساسة. **لا تغيّريه بعد إدخال بيانات حقيقية، واحفظي نسخة منه خارج الخادم** |
| `REQUIRE_STAFF_2FA` | `true` (افتراضي) لجعل التحقق الثنائي إلزامياً |
| `TRUST_PROXY` | `true` فقط خلف وكيل موثوق (Vercel/Netlify/Nginx) لتفعيل حد المحاولات حسب IP |

`GET|POST /api/v1/users` · `PATCH /api/v1/users/:id` · `PUT /api/v1/users/:id/permissions` ·
`POST /api/v1/users/:id/{reset-password,reset-2fa}` · `GET /api/v1/classes` ·
`GET /api/v1/classes/:id/students` · `POST /api/v1/classes/:id/picture-codes` ·
`GET|POST /api/v1/classes/:id/comments` · `GET /api/v1/audit`

## ملاحظات معروفة

- **حد المحاولات بالذاكرة:** `src/lib/rateLimit.ts` يناسب خادماً واحداً، ويُستبدل بـ Redis عند تشغيل عدة نسخ.
- **ثغرات مكتبة `xlsx`:** المكتبة موروثة من المشروع السابق ولها ثغرات معروفة بلا إصلاح، وستُستبدل بـ `exceljs` في المرحلة 2 عند بناء استيراد الطالبات.
- **تواريخ الفصلين الدراسيين في البذرة تقريبية**، وتُعدَّل وفق التقويم الرسمي.
