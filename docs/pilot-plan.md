# خطة التجربة الميدانية (UAT) — فصلان لمدة أسبوعين

> الهدف: التحقق من أن المنصة تعمل في يوم دراسي حقيقي، وجمع ملاحظات المعلمة والمشرفة والطالبات قبل التعميم.
> النطاق: فصلان من الرابع، معلمة لغتي واحدة (أو اثنتان)، المشرفة التربوية، القائدة.

## قبل البدء (الأسبوع 0)

- [ ] النشر على الخادم النهائي داخل المملكة عبر HTTPS (`docs/operations-runbook.md`)
- [ ] نجاح `scripts/restore-test.sh` على أول نسخة احتياطية
- [ ] حفظ `FIELD_ENCRYPTION_KEY` و`backup_passphrase` في خزنة منفصلة لدى شخصين
- [ ] إنشاء الحسابات، استيراد التوزيع الرسمي والطالبات من «نور»، ضبط الأوزان
- [ ] **مراجعة المحتوى** من معلمة لغتي: بنك الأسئلة النموذجي (32 سؤالاً) وكلمات وجمل الألعاب المدمجة (`src/lib/gameWords.ts`) — حذف أو تعديل ما لا يناسب
- [ ] الجلسات التدريبية 1–3 (`docs/training-guide.md`)
- [ ] **إشعار أولياء الأمور** بالمنصة وبالبيانات المحفوظة (نموذج في القسم الأخير)
- [ ] تجربة الأجهزة اللوحية/أجهزة المعمل في الفصل نفسه: الدخول بالصور، الصوت، الألعاب دون اتصال

## مؤشرات النجاح (نهاية الأسبوعين)

| المؤشر | الهدف | المصدر |
|---|---|---|
| سيناريوهات القبول الناجحة | ≥ 11 من 12 | استمارة الملاحظة |
| أيام رُصد فيها الحضور على المنصة | ≥ 90٪ من أيام الدوام | تقرير الحضور |
| طالبات دخلن للمنصة مرة على الأقل | ≥ 90٪ | «آخر دخول» في صفحة الفصل |
| طالبات لعبن أسبوعياً | ≥ 70٪ | لوحة الألعاب |
| رضا المعلمة (1–5) | ≥ 4 | الاستبانة |
| أعطال توقف العمل | 0 | سجل الحوادث |
| تطابق ملف «نور» مع الرصد اليدوي | 100٪ لعينة 10 طالبات | مراجعة يدوية |

|---|---|
| الأحد (أ1) | دخول الطالبات + جلسة ألعاب في الحصة |

| أ2 | رصد كامل للدرجات + تقارير + زيارة إشرافية عبر المنصة |
| نهاية أ2 | اختبار استعادة النسخ + الاستبانة + قرار التعميم |

## سجل الملاحظات (يُملأ يومياً)

| التاريخ | المستخدمة | الشاشة | ما حدث | الأثر (عائق/مزعج/اقتراح) | الإجراء |
|---|---|---|---|---|---|
| | | | | | |

**أسئلة الاستبانة الختامية للمعلمة:**
1. هل وفّرت المنصة وقتاً مقارنة بالطريقة السابقة؟ في أي مهمة تحديداً؟
2. ما أكثر شاشة استخدمتِها؟ وما أقلها؟ لماذا؟
3. هل كانت نتائج التصحيح الآلي عادلة؟ أي سؤال صُحّح بشكل غير متوقع؟
4. هل ساعد التحليل المهاري في تحديد من تحتاج دعماً؟
5. هل تفاعلت الطالبات مع الألعاب؟ أيها أكثر؟
6. ما الشيء الوحيد الذي لو تغيّر لاستخدمتِ المنصة أكثر؟

## نموذج إشعار أولياء الأمور

> ولي أمر الطالبة الكريم،
>
> تستخدم مدرستنا منصة «لغتي» الإلكترونية لمادة لغتي للصف الرابع، لتسجيل الحضور والدرجات، وحل الواجبات والاختبارات، والتدريب بألعاب تعليمية.
>
> **البيانات المحفوظة:** اسم الطالبة، رقم الهوية، تاريخ الميلاد، اسم ولي الأمر ورقم جواله، ملاحظات صحية تخص التعلّم (إن وُجدت)، الحضور والسلوك والدرجات ونتائج الأنشطة.
>
> **الحماية:** البيانات محفوظة على خوادم داخل المملكة، والبيانات الحساسة مشفّرة، ولا يطّلع عليها إلا معلمة المادة والإدارة المخوّلة، وكل اطلاع يُسجَّل. لا تُستخدم أي إعلانات أو أدوات تتبع، ولا تُشارك البيانات مع أي جهة.
>
> **حقوقكم:** يحق لكم طلب نسخة من بيانات ابنتكم، أو تصحيحها، أو طلب حذفها عند انتهاء الحاجة إليها، بالتواصل مع إدارة المدرسة.
>
> دخول الطالبة يتم ببطاقة صور خاصة بها؛ نرجو مساعدتها على الحفاظ على سريتها.
