# دليل التدريب — منصة لغتي

> ثلاث جلسات قصيرة للمعلمات، وجلسة للقائدة والمشرفة، و10 دقائق للطالبات داخل الحصة.
> كل جلسة عملية على جهاز المتدربة نفسها، بحساب حقيقي في بيئة التجربة.

---

## الجلسة 0 — قبل التدريب (مدير النظام / القائدة) · 30 دقيقة

- [ ] إنشاء حسابات المعلمات والمشرفة (المستخدمون والصلاحيات ← «＋ مستخدمة جديدة») وإسناد الفصول.
- [ ] تسليم كل مستخدمة كلمة مرورها المؤقتة **يداً بيد أو برسالة خاصة** (لا في مجموعات).
- [ ] استيراد التوزيع الرسمي: توزيع المنهج ← «قالب Excel» ← املئيه ← «استيراد».
- [ ] ضبط أوزان التقييم وسلم التقديرات وفق لائحة التقويم المعتمدة: سجل الدرجات ← «⚙️ الأوزان».
- [ ] التأكد من تثبيت **Google Authenticator** أو **Microsoft Authenticator** على جوال كل معلمة قبل الجلسة 1.

## الجلسة 1 — الدخول والطالبات · 45 دقيقة

| الدقائق | الموضوع | التمرين |
|---|---|---|
| 0–10 | أول دخول وتفعيل التحقق الثنائي | ادخلي بكلمة المرور المؤقتة ← امسحي رمز QR ← أدخلي الرمز ← غيّري كلمة المرور من «حسابي والأمان» |
| 10–20 | استيراد الطالبات من «نور» | صدّري كشف فصلك من «نور» بصيغة Excel ← الفصول ← فصلك ← «استيراد من نور» ← معاينة ← استيراد |
| 20–30 | بطاقات دخول الطالبات | «توليد رموز جديدة» ← «طباعة البطاقات» (A4: 8 بطاقات في الصفحة) |
| 30–40 | الحضور اليومي | تبويب «الحضور» ← «الباقيات حاضرات» ← غيّري حالتين ← «حفظ الحضور» |
| 40–45 | ملف الطالبة | افتحي طالبة ← سجّلي سلوكاً إيجابياً وملاحظة أكاديمية |

**نقاط يجب التأكيد عليها:**
- رمز الصور للطالبة **يظهر مرة واحدة فقط** عند التوليد. إن ضاعت البطاقة: ولّدي رمزاً جديداً لها وحدها.
- البيانات الحساسة (الهوية، الجوال، الصحة) مشفّرة، وكل اطلاع عليها يُسجَّل.
- الملاحظات «الخاصة» لا تراها المشرفة؛ الافتراضي أنها تراها.

## الجلسة 2 — المنهج والدرجات · 60 دقيقة

| الدقائق | الموضوع | التمرين |
|---|---|---|
| 0–15 | توزيع المنهج | علّمي درسين «منفّذ» ← لاحظي تغيّر نسبة التغطية ← «تأجيل أسبوع» لدرس ← راجعي ما تحرّك |
| 15–25 | التقويم | أضيفي اختباراً قصيراً ← اسحبيه ليوم آخر ← «تصدير iCal» لتقويم الجوال |
| 25–45 | سجل الدرجات | «＋ تقييم» (اختاري المهارات!) ← رصد بلوحة المفاتيح (Enter للنزول) ← «غ» للغياب و«ع» للعذر ← الصقي عموداً من Excel |
| 45–55 | التقارير | «📈 التقارير» ← التقرير الجماعي ← بطاقة طالبة ← «⬇️ تنزيل PDF» |
| 55–60 | التصدير لـ«نور» | تصدير ← «ملف نور» ← افتحيه في Excel |

**نقاط يجب التأكيد عليها:**
- **وسم التقييم بالمهارات** هو ما يصنع التحليل المهاري والخريطة الحرارية — بدونه لا تظهر.
- **«بعذر» لا يُحتسب، و«غائبة» صفر** — اختاري بدقة.
- **الاعتماد** يقفل الدرجات؛ بعده كل تصحيح يحتاج سبباً ويُسجَّل بالقيمة القديمة والجديدة. لا تعتمدي قبل اكتمال الرصد.

## الجلسة 3 — الاختبارات والألعاب · 45 دقيقة

| الدقائق | الموضوع | التمرين |
|---|---|---|
| 0–10 | بنك الأسئلة | أضيفي سؤال «ملء فراغ» إملائياً (المطابقة: إملائية صارمة) وآخر نحوياً (متساهلة) — لاحظي الفرق |
| 10–15 | المولّد من المفردات | «⚙️ توليد من المفردات» ← اللام الشمسية/القمرية ← راجعي ← احفظي |
| 15–25 | إنشاء اختبار | «＋ اختبار» ← قالب «اختبار قصير — الرسم الإملائي» ← توليد ← نموذجان ← حفظ |
| 25–35 | النشر والحل | انشري لفصلك إلكترونياً ← ادخلي بحساب طالبة تجريبية على جهاز آخر وحلّيه ← النتائج ← صححي السؤال المفتوح ← لاحظي انتقال الدرجة للسجل |
| 35–40 | الطباعة الورقية | «أوراق بأسماء الطالبات» ← نموذج الإجابة |
| 40–45 | الألعاب | لوحة «الألعاب التعليمية» ← أصعب العناصر ← إصدار شهادة تقدير |

**متى «متساهلة» ومتى «إملائية صارمة»؟** في أسئلة **الرسم الإملائي** فقط تكون صارمة (الهمزة والتاء جزء من المهارة). في النحو والفهم والصرف: متساهلة، حتى لا تُعاقَب الطالبة على خطأ إملائي في سؤال لا يقيسه.

## جلسة القائدة والمشرفة · 30 دقيقة

**القائدة:** المستخدمون والصلاحيات (منح/سحب صلاحية، فك قفل، إعادة ضبط التحقق الثنائي) · اعتماد الدرجات وفكّه بسبب · سجل التدقيق · **حقوق البيانات**: تصدير بيانات طالبة لولي الأمر، والحذف النهائي (بعد الأرشفة).

**المشرفة:** كل الشاشات للقراءة فقط · نسبة تغطية المنهج لكل فصل · التقارير والتصدير · **الملاحظات الإشرافية** (على الفصل أو على طالبة) — القناة الوحيدة للكتابة، ولا تعدّل أي بيانات للمعلمة.

---

## دقائق الطالبات الأولى (داخل الحصة) · 10 دقائق

1. وزّعي البطاقات المطبوعة.
2. على السبورة: افتحي `/student-login` واشرحي: **رمز الفصل ← اختاري اسمك وصورتك ← اضغطي صورك الأربع بالترتيب**.
3. دعيهن يجرّبن «🎮 ألعابي» ← «حديقة الشمس والقمر» جولة واحدة.
4. ذكّريهن: **البطاقة سرية مثل مفتاح البيت**، ولا تُعطى لصديقة.

> إن قالت الطالبة «توقفي قليلاً»: أخطأت 5 مرات — ولّدي لها رمزاً جديداً من صفحة الفصل.

## بطاقة مرجعية سريعة للمعلمة (اطبعيها)

| أريد أن… | المكان |
|---|---|
| أسجّل الحضور | الفصول ← فصلي ← الحضور |
| أرصد درجة | سجل الدرجات ← اضغطي الخلية ← اكتبي ← Enter |
| أُدخل غياباً في اختبار | اكتبي **غ** (بلا عذر = صفر) أو **ع** (بعذر = لا يُحتسب) |
| أطبع شهادة/بطاقة طالبة | التقارير ← اسم الطالبة ← تنزيل PDF |
| أؤجّل درساً | توزيع المنهج ← الدرس ← «تأجيل أسبوع» |
| طالبة نسيت صورها | الفصول ← فصلي ← بطاقات الدخول ← اختاري اسمها ← توليد |
| نسيت كلمة مروري / فقدت جوالي | تواصلي مع القائدة |
